## Question

What is the smallest clear interface that lets a user gather facts first, move into argument construction, and choose from the gathered list without losing orientation or overcrowding the existing command-desk layout?

## Resolution requirements

- Create a cheap interactive or visual prototype using the selected Fact Library contract.
- Compare only the smallest plausible navigation patterns, such as two stages, tabs, or a fact drawer beside the board.
- Show first use, adding several facts, entering argument construction, selecting facts, returning to fact gathering, and an empty or incomplete fact state.
- Show usage counts and destination badges, ordered attachments, inline global editing, **Open in Gathered Facts**, **Remove from here**, and both choose-existing and create-here paths.
- Show the confirmation that lists affected destinations before deleting a used fact.
- Preserve plain-language labels, keyboard reachability, visible focus, usable narrow-screen behavior, and the read-only Preview mode.
- Test the prototype with the user before resolving the ticket; do not infer the user's reaction.
- Link the chosen prototype and record why it supports the gather-first mental model.
